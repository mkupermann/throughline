# Commit Style

Use the format type(scope): summary.

Types are feat, fix, docs, refactor, test, chore.

Keep the subject line under sixty characters.

Use the imperative mood in the subject.

Leave a blank line between subject and body.

Wrap the body at seventy-two characters.

Reference the issue number in the footer when applicable.
