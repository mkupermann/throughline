# Release Notes

Gather merged pull requests since the last tag.

Group them by type: features, fixes, breaking changes.

Write one bullet per pull request with its title and number.

Link each bullet to the pull request URL.

Highlight breaking changes in a separate section at the top.

Keep the tone concise and factual.

Do not include internal refactors unless they affect users.

End with a contributors section listing pull request authors.

Save the draft to the repository root as RELEASE_NOTES.md.
