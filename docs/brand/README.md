# Throughline identity

The mark combines T and L in one continuous form. Its horizontal strokes suggest a line of work that continues across sessions. The shape uses filled geometry and stays legible at favicon size.

Use ink `#151b1e`, paper `#f3efe6`, and restrained terracotta `#c55234`. Keep one quarter of the mark width as clear space. Do not stretch, add gradients, or turn it into a network diagram. The sidebar inherits its foreground colour; the favicon has a fixed dark field.

`mark.svg` is the standalone vector; `wordmark.svg` is the README banner. `Logo.tsx` and `web/public/favicon.svg` share the mark geometry. The banner uses system sans-serif typography; the lettering is not a proprietary typeface.
