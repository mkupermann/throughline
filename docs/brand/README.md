# Throughline identity

One continuous path carries the line forward. The geometric mark represents retained context across sessions, tools and teams. Rounded turns give it a clear silhouette without relying on letters, gradients or decorative nodes.

## Assets

- `mark.svg`: standalone blue mark on a transparent background.
- `throughline-wordmark.svg`: primary wordmark for light backgrounds.
- `throughline-wordmark-dark.svg`: wordmark for dark backgrounds.
- `wordmark.svg`: compatibility copy of the primary wordmark.
- `web/src/components/Logo.tsx` and `web/public/favicon.svg`: matching application assets.

## Use

Colors follow `web/src/styles/tokens.css`: accent #0550ae / #58a6ff and text #1f2328 / #c9d1d9. Use the dark wordmark on dark backgrounds, the light wordmark on light backgrounds. Keep at least 8 units clear space around the 56-unit mark. Minimum mark size: 16px; use the mark alone below 180px wordmark width. Do not distort, rotate, add gradients or separate the connected path.

The wordmark uses a system sans-serif stack, avoiding third-party font downloads. SVG source remains editable. This is a project-authored vector identity, not a trademark clearance claim.
